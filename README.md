# Tish playground

A **codepen-style** in-browser sandbox for the Tish language. Edit `.tish` files in a multi-buffer editor, hit Run, and the same browser tab compiles + executes your code — no backend, no build step on your machine, no account.

Powered by [`tish-ide-panels`](../tish-ide-panels)'s `SandboxIde` component, which is also embedded inside `tish-learn` lessons and (optionally) the Tauri-based `tish-ide` desktop IDE. Editing the playground edits the same component all three hosts share.

## Codepen-style features

| Affordance | What happens |
|---|---|
| **↗ Share** | Copies a paste-able URL with the current files encoded in `#share=…`. Anyone opening that URL gets the same sandbox in their browser. Zero backend — the entire pen lives in the URL. |
| **⌬ Embed** | Copies an `<iframe src="…?embed=1#share=…" sandbox="allow-scripts allow-same-origin">` snippet. Drop it in any blog / doc / static site and the sandbox renders inline at 480px. |
| **⑂ Fork** | When you've opened someone else's `#share=…` URL, edits don't persist (you're viewing their pen). Click Fork to claim it as yours: edits start saving to your local storage and the URL clears. |
| **⇱ New window** | Pops the current sandbox out into a standalone tab via `BroadcastChannel`-synced session — see the open-in-new-window protocol in [`tish-ide-panels/README.md`](../tish-ide-panels#open-in-new-window-protocol). |
| **≡ Examples** | A small dropdown of curated starter sandboxes (Counter, Hello console, FizzBuzz, Tiny todo). Selecting one replaces the editor with a fresh local pen. |

The share format is URL-safe base64 of a JSON payload — no compression yet, so payloads up to ~5KB stay well under modern URL length limits. See `encodeSharePayload` / `decodeSharePayload` in [`tish-ide-panels/src/SandboxIde.tish`](../tish-ide-panels/src/SandboxIde.tish) for the schema (versioned with `v: 1`).

### Embed mode

A URL with `?embed=1` (or a `<iframe>` snippet generated by the Embed button) mounts the sandbox in `mode="embed"`: tight toolbar, no header chrome, no localStorage persistence. Designed to drop into any HTML page:

```html
<iframe
  src="https://tishlang.com/playground?embed=1#share=eyJ2IjoxLCJmaWxlcyI6W…"
  style="width:100%;height:480px;border:1px solid #ccc;border-radius:6px"
  sandbox="allow-scripts allow-same-origin"></iframe>
```

## Layout

| Path | Role |
|------|------|
| [`app/main.tish`](app/main.tish) | Mounts the shell into `#app`. |
| [`app/shell.tish`](app/shell.tish) | Thin wrapper: default file contents, examples menu, and the `mountSandboxIde({...})` call. ~150 lines. |
| [`app/web-runtime.tish`](app/web-runtime.tish) | Lattish runtime bundled separately and loaded inside the web-preview iframe. |
| [`public/`](public/) | Static assets: `index.html`, generated `playground.js`, `tish_vm*.wasm`, `tish_compiler*.wasm`, `lattish-runtime.js`. |
| [`dev-server.tish`](dev-server.tish) | Static file server (Tish) for local dev. |
| [`build.sh`](build.sh) | One-shot CLI builder (no `just` required). |

The actual editor / terminal / web preview / file browser / layout splits / hotkeys / persistence / share / fork / new-window logic all lives in [`tish-ide-panels`](../tish-ide-panels) — the playground itself is now a ~150-line "preset" on top of that shared component.

## Prerequisites

- [Rust](https://rustup.rs/) + `just` (optional)
- [`wasm-bindgen-cli`](https://rustwasm.github.io/wasm-bindgen/reference/cli.html): `cargo install wasm-bindgen-cli`
- `rustup target add wasm32-unknown-unknown`
- Sibling checkout of **Tish** (default: `../tish`). Override with `TISH_ROOT`.

**Local Tish development**: The playground uses the local tish repo (not npm). After pulling tish changes, run `npm run install-tish` to reinstall the CLI, then `npm run verify` to confirm JSX text (e.g. `<h1>Web preview works!</h1>`) compiles correctly.

## Build & run

```bash
just dev
```

Builds the UI, VM WASM, and compiler WASM, then serves **http://127.0.0.1:8765** via the Tish dev server.

Individual steps:

```bash
just build-app      # Tish → public/dist/playground.js
just build-vm       # tish_wasm_runtime → public/dist/tish_vm*.wasm
just build-compiler # tishlang_compiler_wasm → public/dist/tish_compiler*.wasm
```

Or without `just`:

```bash
npm run build       # bash build.sh — same artefacts
```

## Try the share flow locally

1. Run `just dev` (or `npm run build && npm run start`).
2. Open <http://127.0.0.1:8765>, edit `main.tish`, hit Run.
3. Click **↗ Share** → paste the URL into a private window. The same sandbox should rehydrate.
4. Click **⌬ Embed** → paste the `<iframe>` into any HTML file and open it. The pen renders inline.
5. Open the shared URL in a fresh browser → edits don't persist (the "shared" badge is on). Click **⑂ Fork** → edits start saving locally, the URL clears.

## Swapping panels

The individual panels (editor textarea, terminal `<pre>`, web-preview iframe, file list) live in [`tish-ide-panels/src/`](../tish-ide-panels/src/). To replace one — say, swap the textarea editor for CodeMirror — fork that package, ship a `EditorPanelCodemirror` export, and the shell picks it up at `import { EditorPanelCodemirror } from "tish-ide-panels"`. See [`tish-ide-panels/README.md`](../tish-ide-panels#whats-in-here) and the older [`PANELS.md`](PANELS.md) for the per-panel API contracts.
